React Native Portfolio (Expo Web)

A personal portfolio built with React Native (Expo) and deployed as a web application using GitHub Pages.  
This project showcases my skills, projects, and contact information in a simple single-page navigation format.

Live Demo:
https://Giretalm.github.io/react-folio/


Project Overview:
This portfolio is a single-page application built using Expo and React Native components. 
It uses multiple pages using internal state navigation instead of a full routing system.

Sections include:
- Home
- About Me
- Projects
- Contact Form

Features:
- Responsive layout using React Native Web
- Navigation between sections without page reload
- Project showcase cards with external links
- Simple contact form UI (with validation alerts)
- Styled dark-themed UI
- Hosted on GitHub Pages
